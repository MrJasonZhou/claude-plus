# claude-plus

## Conventions

**Code comments are English.** This covers `install-claude-plus.sh`, the
`claude-plus.sh` it generates via the heredoc, and every script under
`notify/`. User-facing output from the scripts is English too.

**Documentation is multilingual and stays in sync.** `README.md` is English,
`README.zh-CN.md` Chinese, `README.ja.md` Japanese. Any change to one of them
must land in all three in the same commit — no "translate it later".
