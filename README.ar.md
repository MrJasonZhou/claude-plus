# Claude Plus

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Italiano](README.it.md) | [Português](README.pt.md) | العربية

أمران لا يقوم بهما Claude Code نيابة عنك، يُنجَزان وأنت بعيد عن لوحة المفاتيح.

- **إبقاء النافذة مفتوحة** — تُفتح نافذة جديدة مدتها خمس ساعات فور إعادة تعيين السابقة، حتى لو لم يكن أحد يستخدم Claude Code، فتجد عند عودتك حصة كاملة قيد الاستخدام بالفعل.
- **التنبيه** — حين يتوقف ذلك عن العمل يخبرك: عبر Bark أو ntfy أو البريد الإلكتروني أو أي قناة أخرى تختار وصلها.

أصبح Claude Code نفسه يستأنف الجلسة بعد بلوغ حد الاستخدام: انظر "Continue automatically at usage limit" في `/config`. كان Claude Plus يفعل ذلك أيضًا قبل الإصدار 3.0.0، ومنذ ذلك الإصدار يتركه لـ Claude Code.

## ما الفائدة

**وقت فتح النافذة هو ما يحدد وقت انتهائها.** تبدأ نافذة الخمس ساعات من أول طلب لك، لا من ساعة ثابتة. ابدأ العمل في التاسعة صباحًا فتمتد النافذة من 9:00 إلى 14:00؛ وإذا استنفدت الحصة عند 11:00 بقيت محجوبًا حتى 14:00. أما لو كان طلب صغير قد فتح النافذة عند 6:00، لانتهت عند 11:00 — أي في اللحظة نفسها التي تنفد فيها حصتك — وكانت حصة جديدة في انتظارك. ومع نافذة تعمل دائمًا، تكون هناك نافذة قيد التشغيل حين تبدأ: فما تبقى منها حصة كانت ستضيع لولا ذلك، والحصة الجديدة على بُعد خمس ساعات على الأكثر، وغالبًا أقل بكثير.

**معرفة متى توقف عن إفادتك.** إبقاء النوافذ مفتوحة لا يعمل إلا ما دام تسجيل دخولك صالحًا والمجدول يعمل؛ فإذا توقف أيٌّ منهما لم يحدث شيء على الإطلاق. ينتبه Claude Plus إلى كلتا الحالتين ويخبرك بها، بدل أن يفشل صامتًا طوال عطلة نهاية الأسبوع.

## المتطلبات

نظام Linux مع `claude` و`jq` و`at` (مع تشغيل `atd`) و`flock` و`timeout` و`date` من GNU.

```bash
sudo systemctl enable --now atd
```

## التثبيت

```bash
npx @claude-plus/claude-plus
```

أو من نسخة مستنسخة:

```bash
git clone https://github.com/MrJasonZhou/claude-plus.git
cd claude-plus
bash install-claude-plus.sh
```

يغلّف المثبِّت شريط الحالة الموجود لديك، فيبقى ظاهرًا كما كان تمامًا؛ وهذا هو التغيير الوحيد الذي يجريه على إعداداتك. ويُحفظ ملف `settings.json` احتياطيًا قبل ذلك، كما أن إعادة تشغيل المثبِّت ترقية نظيفة لا نسخة ثانية. وتحتفظ الترقية بالتشغيل المجدول التالي وحالته وأداة التنبيه الخاصة بك. والترقية من 2.x تزيل كذلك الخطافات التي كانت تلك الإصدارات تضيفها لاستئناف الجلسات.

## الاستخدام

في الاستعمال اليومي لا شيء يحتاج إلى تشغيل — فهو يعمل وحده. وحين تريد الاطلاع:

```bash
~/.claude/claude-plus/claude-plus.sh status   # هل المجدول يعمل، وما المجدول، وهل المصادقة سليمة
tail -f ~/.claude/claude-plus/claude-plus.log # ما الذي كان يفعله
```

## التنبيهات

يبقى Claude Plus صامتًا ما لم يكن هناك ما يستدعي تدخلك، ولا يبلغك إلا بأربعة أمور:

| | |
|---|---|
| **تسجيل الخروج** | انتهت صلاحية دخولك إلى Claude Code، فلا يمكن فتح شيء حتى تسجل الدخول من جديد |
| **فشل متكرر** | فشلت عدة عمليات إحماء متتالية |
| **توقف المجدول** | تأخر تشغيل مجدول كثيرًا عن موعده، فلا تُبقى أي نافذة مفتوحة؛ وغالبًا يكون `atd` غير مشغّل |
| **العودة إلى الوضع الطبيعي** | تعافى من أيٍّ من الحالات أعلاه |

يُبلَّغ عن كل أمر مرة واحدة، لا مع كل محاولة إعادة، فمشكلة تقع أثناء الليل تكلفك رسالة واحدة. أما حدود الاستخدام نفسها فلا يُعلَن عنها أبدًا: فهي أمر معتاد، وClaude Code يستأنف بعدها من تلقاء نفسه.

ولاختيار الطريقة التي يصلك بها الخبر، انسخ أحد النماذج واملأ مفتاحك أو خادمك:

```bash
cd ~/.claude/claude-plus
cp notify/bark.sh.sample notify.sh      # أو ntfy.sh.sample أو email.sh.sample
chmod +x notify.sh                      # استخدم 700 لنموذج البريد لأنه يحتوي على كلمة مرور
$EDITOR notify.sh
./claude-plus.sh notify-test            # تأكد من وصوله إليك
```

أداة التنبيه ليست سوى ملف تنفيذي يستقبل `CP_EVENT` و`CP_MESSAGE` و`CP_HOST`، لذا فإن Telegram أو Slack أو خطاف ويب أو `mail` كلها مسألة إعادة كتابة سطر واحد. ونسختك تبقى بعد إعادة التثبيت.

## الملفات

كل شيء داخل `~/.claude/claude-plus/`:

| | |
|---|---|
| `claude-plus.sh` | السكربت نفسه |
| `notify.sh` | أداة التنبيه الخاصة بك بعد إعدادها |
| `notify/` | نماذج للنسخ منها |
| `claude-plus.log` | ما الذي كان يفعله |
| `state/` | سجلات داخلية |

## إلغاء التثبيت

```bash
npx @claude-plus/claude-plus uninstall
```

أو من نسخة مستنسخة: `bash install-claude-plus.sh uninstall`.

يعدّل ملف `settings.json` الحالي في مكانه ولا يزيل منه إلا ما أضافه Claude Plus: يعود شريط الحالة الخاص بك، وتبقى كل الإعدادات والخطافات الأخرى كما هي تمامًا — بما فيها تلك التي أُضيفت بعد تثبيت Claude Plus. تُلغى مهامه المجدولة ويُحذف `~/.claude/claude-plus/`، ومعه ملف `notify.sh` الخاص بك. تشغيله مرة ثانية لا يسبب أي ضرر.

إذا قام برنامج آخر لاحقًا بتغليف شريط الحالة لديك من فوق Claude Plus، فإن إلغاء التثبيت لن يعطّله. يُترك سكربت تمرير صغير كي يستمر ذلك البرنامج في العمل، ويخبرك المُلغي بذلك؛ شغّله مرة أخرى حين لا يعود هناك ما يحتاجه. والترقية في الحالة نفسها تبقى داخل سلسلة ذلك البرنامج بدل أن تغلّفه بدورها.

تُحفظ بجانبه نسخة من `settings.json` كما كان قبيل إلغاء التثبيت مباشرة، وكذلك النسخ التي أُنشئت عند التثبيت، تحسبًا لحاجتك يومًا إلى الرجوع يدويًا.
