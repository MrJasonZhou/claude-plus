# Claude Plus

ثلاثة أمور لا يقوم بها Claude Code نيابة عنك، تُنجَز وأنت بعيد عن لوحة المفاتيح.

- **الاستئناف** — الجلسة التي أوقفها حد الاستخدام تعاود العمل من تلقاء نفسها لحظة إعادة تعيين الحد، وتكمل ما كان قيد التنفيذ.
- **إبقاء النافذة مفتوحة** — إن لم يكن هناك ما يُستأنف، تُفتح نافذة جديدة مدتها خمس ساعات على أي حال، كي يقع موعد إعادة تعيينها خارج ساعات عملك لا في منتصفها.
- **التنبيه** — حين لا يعود قادرًا على المتابعة وحده، يخبرك: عبر Bark أو ntfy أو البريد الإلكتروني أو أي قناة أخرى تختار وصلها.

## ما الفائدة

**التعافي بعد بلوغ حد الخمس ساعات.** في العادة يعني بلوغ الحد أن الجلسة تتوقف ببساطة، فتعود لاحقًا لتشغيلها يدويًا. يتولى Claude Plus إعادة تشغيلها عنك لحظة إعادة تعيين الحد، فيستأنف العمل من حيث توقف — حتى وأنت نائم أو بعيد عن مكتبك.

**وقت فتح النافذة هو ما يحدد وقت انتهائها.** تبدأ نافذة الخمس ساعات من أول طلب لك، لا من ساعة ثابتة. ابدأ العمل في التاسعة صباحًا فتمتد النافذة من 9:00 إلى 14:00؛ وإذا استنفدت الحصة عند 11:00 بقيت محجوبًا حتى 14:00. أما لو كان طلب صغير قد فتح النافذة عند 6:00، لانتهت عند 11:00 — أي في اللحظة نفسها التي تنفد فيها حصتك — وكانت حصة جديدة في انتظارك. إبقاء نافذة تعمل دائمًا يدفع موعد إعادة التعيين إلى ما قبل ساعات عملك بدلًا من منتصفها.

**معرفة متى توقف عن إفادتك.** التعافي التلقائي يعمل ما دام تسجيل دخولك صالحًا، فإذا انتهت صلاحيته لم يعد شيء يعمل. ينتبه Claude Plus إلى هذه الحالة ويخبرك بها، بدل أن يفشل صامتًا طوال عطلة نهاية الأسبوع.

## ما لن يفعله

الاستئناف يعني الكتابة داخل الطرفية التي كنت تعمل فيها، ولذلك فهو شديد الحذر في اختيار موضع الكتابة. لا تُستأنف الجلسة إلا إذا كانت ما تزال موجودة، دون أن تُمَس، تمامًا كما تركها الحد. أما إن أغلقتها أو انتقلت إلى غيرها أو بدأت شيئًا آخر في تلك الطرفية، فإن Claude Plus يتركها وشأنها ويبقى صامتًا. والجلسات التي تعمل خارج tmux لا تُستأنف أبدًا — إذ لا يوجد مكان للكتابة فيه.

أما حدود الاستخدام نفسها فلا يُعلَن عنها أبدًا. فهي أمر معتاد، والاستئناف يتكفل بها، ورسالة في كل مرة لن تكون سوى ضجيج.

## المتطلبات

`claude` و`jq` و`at` (مع تشغيل `atd`) و`flock` و`timeout` و`tmux` و`date` من GNU.

```bash
sudo systemctl enable --now atd
```

## التثبيت

```bash
npx @claude-plus/claude-plus
```

أو من نسخة مستنسخة:

```bash
git clone https://github.com/MrJasonZhou/claude-plus.git
cd claude-plus
bash install-claude-plus.sh
```

يتولى المثبِّت شريط الحالة لديك ويضيف خطافاته الخاصة، مع الإبقاء على شريط الحالة الذي كان لديك وعدم المساس بخطافات الأدوات الأخرى. ويُحفظ ملف `settings.json` احتياطيًا قبل ذلك، كما أن إعادة تشغيل المثبِّت ترقية نظيفة لا نسخة ثانية.

## الاستخدام

في الاستعمال اليومي لا شيء يحتاج إلى تشغيل — فهو يعمل وحده. وحين تريد الاطلاع:

```bash
~/.claude/claude-plus/claude-plus.sh status   # ما المجدول، وما المنتظر، وهل المصادقة سليمة
~/.claude/claude-plus/claude-plus.sh pending  # الجلسات التي تنتظر الاستئناف
tail -f ~/.claude/claude-plus/claude-plus.log # ما الذي كان يفعله
```

## التنبيهات

يبقى Claude Plus صامتًا ما لم يكن هناك ما يستدعي تدخلك، ولا يبلغك إلا بثلاثة أمور:

| | |
|---|---|
| **تسجيل الخروج** | انتهت صلاحية دخولك إلى Claude Code، فلا يمكن فتح شيء حتى تسجل الدخول من جديد |
| **فشل متكرر** | فشلت عدة عمليات إحماء متتالية |
| **العودة إلى الوضع الطبيعي** | تعافى من إحدى الحالتين أعلاه |

يُبلَّغ عن كل أمر مرة واحدة، لا مع كل محاولة إعادة، فمشكلة تقع أثناء الليل تكلفك رسالة واحدة.

ولاختيار الطريقة التي يصلك بها الخبر، انسخ أحد النماذج واملأ مفتاحك أو خادمك:

```bash
cd ~/.claude/claude-plus
cp notify/bark.sh.sample notify.sh      # أو ntfy.sh.sample أو email.sh.sample
chmod +x notify.sh                      # استخدم 700 لنموذج البريد لأنه يحتوي على كلمة مرور
$EDITOR notify.sh
./claude-plus.sh notify-test            # تأكد من وصوله إليك
```

أداة التنبيه ليست سوى ملف تنفيذي يستقبل `CP_EVENT` و`CP_MESSAGE` و`CP_HOST`، لذا فإن Telegram أو Slack أو خطاف ويب أو `mail` كلها مسألة إعادة كتابة سطر واحد. ونسختك تبقى بعد إعادة التثبيت.

## الملفات

كل شيء داخل `~/.claude/claude-plus/`:

| | |
|---|---|
| `claude-plus.sh` | السكربت نفسه |
| `notify.sh` | أداة التنبيه الخاصة بك بعد إعدادها |
| `notify/` | نماذج للنسخ منها |
| `claude-plus.log` | ما الذي كان يفعله |
| `state/` | سجلات داخلية |

## إلغاء التثبيت

```bash
atrm "$(cat ~/.claude/claude-plus/state/at_job)"
cp ~/.claude/settings.json.claude-plus-install-backup.<الطابع الزمني> ~/.claude/settings.json
rm -rf ~/.claude/claude-plus
```
